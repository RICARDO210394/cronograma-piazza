# Cronograma Piazza

Seguimiento diario de pendientes (cámaras, botones de pánico, sistema contra incendio y otros) para los 9 centros comerciales Piazza.

## Uso

Abrir `index.html` en el navegador. Esta copia guarda todo en Firebase (proyecto `cronograma-piazza`), así que la información se sincroniza automáticamente sin importar desde qué PC o celular se abra.

También existe la versión en línea, publicada aquí:
